# Nuzka 3.3.0-beta.3

> **เวอร์ชันทดสอบ / Test version**

- ตั้งพื้นหลังเคลื่อนไหวแยกได้ทีละฉาก (Starting soon, Be right back, Ending, VS) เลือกที่ช่อง "ใช้กับ" ในการ์ดฉากคั่นรายการ และกด "ใช้พื้นหลังตัวกลาง" เพื่อคืนค่า
- หน้า VS แสดง BO และเกมที่เท่าไหร่ (เช่น BO5 · GAME 4) ชื่อทีมยาวย่อให้พอดี ไม่ทับตัว VS
- ฉาก Starting soon / Be right back / Ending: ป้ายล่างแสดง BO แทนชื่อแมตช์ยาวๆ
- สกอร์บอร์ดแสดง BO และเกมที่เท่าไหร่ (จาก beta.2)

---

- The animated background can now be set per scene (Starting soon, Be right back, Ending, VS): pick the
  scene in "Applies to" on the scenes card, and press "Use the shared background" to undo it.
- The VS screen shows the best-of and the current game (for example BO5 · GAME 4), and long team names shrink
  to fit instead of running into the VS mark.
- Break scenes show BO in the bottom tag instead of the long match title.
- The scoreboard shows the best-of and current game (from beta.2).
