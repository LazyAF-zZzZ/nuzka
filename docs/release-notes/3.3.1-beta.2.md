# Nuzka 3.3.1-beta.2

รุ่นทดสอบ ปรับหน้าตาโปรแกรม

- ปุ่มอัปเดตบนแถบด้านบนเขียนว่า "อัปเดต" แทนเลขเวอร์ชัน (เลขเวอร์ชันยังอยู่ในคำอธิบายตอนวางเมาส์)
- เส้นสีทองใต้แถบด้านบนตอนที่ overlay ขึ้นจอ (ตอนที่ป้าย ON AIR ติด)
- หน้าที่ยังไม่มีข้อมูล (หน้าแรก ทีม สายการแข่ง ประวัติดราฟต์ สถิติ) บอกว่าต้องทำอะไรต่อ พร้อมปุ่ม
- หน้าคุมงาน: "รูปลักษณ์" (พื้นหลังและข้อความบนฉาก) พับเก็บได้ ลิงก์ OBS ของทัวร์นาเมนต์ก็พับได้
- สถิติทีม: ตารางฮีโร่เรียงสองคอลัมน์ อ่านง่ายขึ้นเมื่อหน้าต่างแคบ
- ตัวหนังสือสีเทาอ่านง่ายขึ้น และทุกปุ่มมีกรอบทองเมื่อกดแท็บเลือก

Test build. Interface polish.
