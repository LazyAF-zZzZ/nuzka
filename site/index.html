Nuzka – โอเวอร์เลย์แบน/พิค RoV ฟรี สำหรับ OBS

คุมการแบน/พิคและจัดการทัวร์นาเมนต์ RoV จากโปรแกรมเดียว แล้วให้ OBS แสดงโอเวอร์เลย์บนสตรีม

Free draft pick/ban overlay and tournament manager for Arena of Valor (RoV) streams in OBS. A Windows app, formerly ROV Overlay Tool.

What it does

แบน/พิคสด

กดเลือกฮีโร่จากแผงควบคุม โอเวอร์เลย์ใน OBS เปลี่ยนตามทันที พร้อมตัวจับเวลา

Live draft with a timer, driven from the control panel.

จัดทัวร์นาเมนต์

ทีม รายชื่อผู้เล่น สายการแข่งขัน ผลแต่ละเกม และสถิติการแบน/พิค

Teams, rosters, brackets, results and pick/ban stats.

ฉากพัก และกราฟิกเสริม

ฉากเริ่มเร็วๆ นี้ ฉากพัก หน้า VS สกอร์บอร์ด และ lower third

Break scenes, VS screen, scoreboard and lower third.

ปรับดีไซน์ได้

เปลี่ยนสี ฟอนต์ พื้นผิว และจัดวางตำแหน่งของแต่ละโอเวอร์เลย์เอง

Edit colours, fonts, textures and layout per overlay.

ปุ่มลัด

ควบคุมการแข่งขันด้วยคีย์บอร์ด ไม่ต้องสลับหน้าต่าง

Global hotkeys, so you never leave OBS.

ไทย / English

Thai and English. Works offline during a broadcast.

Getting started

  1. ดาวน์โหลดและติดตั้ง Nuzka-win-Setup.exe
    Download and run the installer.
  2. เปิด Nuzka แล้วคัดลอกลิงก์โอเวอร์เลย์ไปใส่เป็น Browser Source ใน OBS
    Copy each overlay link into OBS as a Browser Source.
  3. คุมการแบน/พิคและคะแนนจากแผงควบคุมของ Nuzka
    Run the draft and the score from Nuzka's control panel.
